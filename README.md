NimbusOS is a self-contained desktop environment built with plain HTML, CSS and JavaScript. It is a code challenge am doing to test my skills
Everything — the filesystem, your settings, your documents — lives in this browser's localStorage,so it stays put between visits on this device, but doesn't sync anywhere else.

Download the codes and run the index.html file
You can also see it from https://nimbus-os-two.vercel.app/
